# Support

## Documentation

Start with the `docs/` directory and the README. The
[Architecture](docs/Architecture.md) guide explains the analysis pipeline, and
the [CLI](docs/CLI.md) and [Console](docs/Console.md) references cover every
command.

## Getting help

- Open an issue for bugs and feature requests (see
  [CONTRIBUTING.md](CONTRIBUTING.md)).
- The repository is hosted under `github.com/QYVORA/qyvora-aksum`. For issues
  on other QYVORA projects, use their respective repositories.
- Report security vulnerabilities privately per [SECURITY.md](SECURITY.md) —
  never in a public issue.

## Operating responsibility

AKSUM is an **authorized-use** tool. Only inspect or reverse binaries you are
allowed to analyze. Confirm scope non-interactively with the documented
`--authorized`/`QYVORA_AUTHORIZED` mechanics, and review
`docs/Architecture.md` and `SECURITY.md` before using it in an organization.
